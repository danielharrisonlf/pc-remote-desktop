# PC Remote Desktop 0.6.4 — Ubuntu 1

Primeira distribuição Ubuntu desta revisão, com instalação sem compilação e controle nativo Wayland pelo portal do sistema. Disponível para **Ubuntu 22.04, 24.04 e 26.04 LTS, amd64**.

## Instalar

Baixe e extraia `pc-remote-ubuntu-0.6.4-amd64.tar.gz`, abra o terminal na pasta extraída e execute:

```bash
bash install-ubuntu.sh
```

O instalador confere o Ubuntu, a identidade e a arquitetura do pacote, instala as dependências obrigatórias pelo APT e adiciona PC Remote ao menu. Não exige Node, Rust nem ferramentas de desenvolvimento.

Também é possível instalar diretamente o arquivo `.deb`:

```bash
sudo apt install --no-install-recommends ~/Downloads/pc-remote-desktop-0.6.4-amd64.deb
```

Para conferir os downloads, salve `UBUNTU-SHA256SUMS-0.6.4.txt` junto dos três arquivos desta distribuição e execute `sha256sum -c UBUNTU-SHA256SUMS-0.6.4.txt`. O arquivo compactado também inclui checksums de seu conteúdo.

## Controle no Wayland

Abra **Configurações → Controle no Ubuntu → Autorizar controle** no PC Remote e permita mouse e teclado na janela do sistema. O portal atende aplicativos nativos Wayland; eventos enviados pelo celular não abrem janelas de autorização. Cancelar ou revogar a permissão bloqueia a entrada. **Interromper** cancela textos em andamento, solta as teclas aceitas e mantém a autorização para um posterior **Liberar**.

## Validação

- 107 testes Rust de biblioteca, 38 de frontend, 7 de runtime Linux e 1 de integração do portal aprovados: **153 testes**.
- O mesmo `.deb`, compilado no Ubuntu 22.04, instalado e aberto em imagens limpas de Ubuntu 22.04, 24.04 e 26.04.
- Bibliotecas e atalho conferidos; processo ativo, janela mapeada e botão **Parear celular** identificado na interface embutida, como usuário normal sob D-Bus/Xvfb privados.
- Portal testado com autorização aceita/negada, revogação, mouse, teclado, Unicode, texto de 1024 bytes e interrupção da digitação.

Esta é uma **pré-release Ubuntu**: a janela de autorização, a entrega de eventos em aplicativos nativos e o clipboard ainda precisam ser validados em um desktop GNOME Wayland real. Áudio físico, ações reais de energia e interação com o seletor de arquivos também permanecem fora da validação isolada.

O aplicativo e o pacote Debian continuam na versão **0.6.4**; a tag `v0.6.4-ubuntu.1` identifica esta distribuição Ubuntu. Atualize o Linux instalando o novo `.deb`; pareamentos e configurações são mantidos. A release Windows `v0.6.4` continua atendendo o atualizador automático.
