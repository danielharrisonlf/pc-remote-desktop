# PC Remote Desktop 0.6.4

- Nova identidade visual compartilhada com o Android: símbolo vetorial em obsidiana,
  branco gelo e ciano, aplicado ao ícone do app, bandeja, instalador, sidebar e favicon.
- Ícone Windows com sete resoluções independentes de 16 a 256px e assets PNG/SVG
  para Linux e telas de alta densidade.
- Corrigido evento espúrio no clipboard de imagens Linux: escrever e ler os mesmos
  pixels mantém a sequência; mudanças reais de dimensões continuam sendo detectadas.
- Corrigida perda intermitente de cliques, scroll e movimento X11 ao fechar a conexão.
- Ambiente Linux reproduzível em Docker/Ubuntu 22.04 com Xvfb, D-Bus e áudio virtual:
  105 testes Rust, 7 testes de runtime, 38 testes frontend e 32 repetições XTEST aprovados.

Protocolo, identidade do PC e pareamentos preservados. Instalador Windows assinado
para o atualizador com a mesma chave das versões anteriores; sem Authenticode.
Use Android 0.6.3-kotlin para a identidade visual correspondente.

No Linux, a validação cobre X11 em ambiente isolado. Wayland, ações reais de energia
via logind, dispositivos de áudio físicos e integração com portais do desktop exigem
validação em uma sessão Linux real. Os pacotes Linux são downloads manuais; o
manifesto de atualização automática continua destinado ao Windows.
