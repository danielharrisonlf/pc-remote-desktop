# PC Remote Desktop 0.6.6

- Corrige a mensagem de código expirado para um código incorreto ou digitado no PC errado.
- Um pedido recebido com código válido conserva seu próprio prazo para aprovação, mesmo quando o código expira.
- Corrige corridas entre aprovação, cancelamento e geração de outro código; a credencial é salva antes da resposta de sucesso.
- O painel aguarda a conexão autenticada do celular antes de mostrar pareamento concluído.
- Alinha o anúncio de descoberta aos endereços IPv4 aceitos pelo servidor e registra falhas de descoberta sem dados privados.

Atualize também o [Android para 0.6.8-kotlin](https://github.com/danielharrisonlf/pc-remote-android/releases/tag/v0.6.8-kotlin). Configurações e pareamentos existentes são preservados. Instalador Windows x64 de avaliação, sem Authenticode, com assinatura verificada pelo atualizador.
